integration_instructions Python SDK Quickstart

Direct structural biology workflow using the native FoldCloud Python client: 

import requests
from foldcloud import BioEngine, Structure

# 1. Initialize AWS native connection
client = BioEngine(
    region="us-east-1",
    cache_tier="s3-hybrid"
)

# 2. Fetch AlphaFold predicted coordinates
structure: Structure = client.get_structure(
    accession="P69905",
    format="mmcif"
)

# 3. Access BioPython Chain entity
chain = structure.get_chain("A")
print(f"Mean pLDDT: {structure.mean_plddt:.2f}")
# >> Mean pLDDT: 97.41 (Very High Confidence)
